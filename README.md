# D&D Helper

Веб-приложение для ведения партий **Dungeons & Dragons**.

D&D Helper помогает мастеру и игрокам хранить информацию об игре в одном месте: персонажей, игровые материалы и данные кампании.

## Стек

### Backend

* Python 3
* FastAPI
* SQLAlchemy
* PostgreSQL
* Alembic
* Pydantic
* JWT
* Argon2

### Frontend

* React
* TypeScript
* Vite
* React Router
* Zustand
* TanStack Query
* Material UI
* Tailwind CSS

## Структура проекта

```text
DnD-helper/
├── backend/        # REST API на FastAPI
├── DND_frontend/   # клиентское приложение на React
└── README.md
```
