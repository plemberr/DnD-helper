# Tenzor Frontend

Каркас фронтенда для DnD helper/admin workspace.

## Что уже есть
- React + TypeScript + Vite
- Material UI
- Макет страницы в стиле референса
- Мок-данные для документов, музыки, картинок и звуков

## Запуск
```bash
npm install
npm run dev
```

## Примечание
Проект сейчас собран как интерактивный прототип. Дальше сюда удобно подключать API, форму создания сущностей и полноценный редактор документов.
