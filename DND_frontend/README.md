# Tenzor Frontend

Каркас фронтенда для DnD helper/admin workspace.

## Что уже есть
- React + TypeScript + Vite
- Material UI
- Макет страниц комнаты и админка комнаты для мастера в стиле референса
- Мок-данные для документов, музыки, картинок и звуков

## Запуск
```bash
npm install
npm run dev
```
